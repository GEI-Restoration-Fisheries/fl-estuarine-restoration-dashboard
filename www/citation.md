## Citation

The Florida Estuarine Restoration Database is a free, open-access database for all users. We only ask that you properly cite the database when using the data to generate products, publications, analyses, or when referencing specific trends or statistics obtained from the data in papers, grants, and other communications.

<h2 class="sources-heading">Sources</h2>

The Florida Estuarine Restoration Database was developed through a reproducible workflow, consisting of compilation of existing source datasets, project screening, metadata harmonization, supplemental data completion, duplicate identification and reconciliation, and generation of the final standardized database. For a detailed description of the methodology behind the development of the database, read the published data descriptor.

The table below lists the original data sources used to compile the Florida Estuarine Restoration Database. We are grateful to these organizations - and many individual employees - for providing these data and assisting our efforts to harmonize the data across these various sources.
